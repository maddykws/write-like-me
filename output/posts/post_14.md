A bigger context window is not a memory upgrade. It's a longer desk, not a better brain.

Just because you can paste 200 pages into the prompt doesn't mean the model uses all of it well. Important details in the middle quietly get less attention.

How to use long context wisely:
- Put the most important information at the start and end
- Retrieve and include only what's relevant, not everything
- Don't confuse 'fits in the window' with 'the model reasoned over it'

More context is a tool, not a strategy. Curation still beats volume.
