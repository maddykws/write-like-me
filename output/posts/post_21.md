Leading a team on a 'legacy' Java codebase taught me that legacy is a story we tell, not a fact about the code.

The team had quietly decided the system was old and slow and that was that. Morale followed the story down.

What turned it around:
- We measured instead of assumed (the JVM was fine, the queries weren't)
- We upgraded the runtime and got modern language features for free
- We let people fix things they'd been told not to touch

"Legacy" usually means "nobody's been allowed to care about it." Change that and the code changes too.
